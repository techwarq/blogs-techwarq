# techwarq — blog

hey, it's techwarq. how to build through all the ai jargon and mess — how to pick and build meaningful stuff, and how to actually ship it.

built with next.js.

## run it

```bash
npm install
npm run dev
# open http://localhost:3000
```

## add a post

add an entry to `POSTS` in `lib/posts.ts`. code blocks use `<pre><code class="language-python">` (bash / json / python / text supported) and get VS Code Dark+ highlighting at build time.
